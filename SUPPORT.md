# Support

## Where to get help

| Need | Use |
| --- | --- |
| Bug, documentation problem, or feature request | [Repository issues](https://github.com/NWarila/ubi9-ansible-runner/issues) |
| Vulnerability | [Security policy](SECURITY.md) |

## Current support boundary

The repository currently contains its documentation and lint scaffold. Support
covers those files and the documented local lint command.

There is no published runtime image, build workflow, or release-verification
contract yet. Requests about those future surfaces should wait until their
implementations and documentation are present.

Include commands, output, commit SHAs, and environment details when they help
reproduce a problem.
