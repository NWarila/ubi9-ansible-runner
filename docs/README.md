# Documentation

Documentation for this repository follows the Diataxis framework.

| Quadrant | Path | Purpose |
| --- | --- | --- |
| Tutorials | [`tutorials/`](tutorials/) | Learning-oriented walkthroughs |
| How-to | [`how-to/`](how-to/) | Task-oriented operating guides |
| Reference | [`reference/`](reference/) | Precise interfaces and repository contracts |
| Explanation | [`explanation/`](explanation/) | Architecture and design rationale |
| Decisions | [`decision-records/`](decision-records/) | Repository architecture decisions |

The four documentation quadrants are placeholders until their corresponding
runtime surfaces exist. Current design decisions are indexed in
[`decision-records/README.md`](decision-records/README.md), and maintenance
obligations are recorded in [`TECH-DEBT.md`](TECH-DEBT.md).
