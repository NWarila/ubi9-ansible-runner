# Decision Records

This directory stores repository-scope Architecture Decision Records for
`ubi9-ansible-runner`.

| ADR | Status | Decision |
| --- | --- | --- |
| [ADR-0001](repo/0001-tool-image-runtime.md) | Accepted | Treat the runtime as a tool image that includes Bash and Python. |
| [ADR-0002](repo/0002-separate-engine-from-content.md) | Accepted | Keep the Ansible engine separate from consumer framework and playbook content. |
| [ADR-0003](repo/0003-version-ansible-core-streams.md) | Accepted | Distinguish immutable version tags, moving stream tags, and digest-pinned consumption. |
